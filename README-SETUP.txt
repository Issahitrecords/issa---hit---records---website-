ISSA HIT RECORDS — WEBSITE STARTER
==================================

This is a first static website prototype. It is not published online yet.

WHAT'S INCLUDED
- index.html: website pages and sample content
- style.css: red, black and white responsive design
- script.js: mobile navigation interaction
- assets/audio/: folder for your authorised audio files
- assets/images/: folder for your logo and artist photos

ADD YOUR MUSIC
1. Put your MP3 files in assets/audio/
2. Name them exactly:
   track-01.mp3
   track-02.mp3
   track-03.mp3
3. Or edit index.html to match your own filenames.
4. Replace the sample track titles and artist names in index.html.
5. Test locally by opening index.html in a modern browser.

IMPORTANT AUDIO HOSTING NOTE
This website template can play audio files that are available at its file paths.
For public launch, do not assume free static website hosting is suitable for a large music catalogue or high streaming traffic. Choose an audio host that permits your intended use and check bandwidth, storage, and terms. Only publish music you have the rights and permissions to distribute.

CUSTOMISE THE CONTACT EMAIL
In index.html, replace your-email@example.com with your official label contact email.

LOGO AND IMAGES
Your improved logo artwork is included at assets/images/issa-hit-records-logo.png and displayed in the homepage hero. The header also retains a clean text wordmark for readability. Add artist photos only with permission.

PUBLISHING WITH GITHUB PAGES (STATIC SITE)
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example: issa-hit-records-website.
3. Upload index.html, style.css, script.js and the assets folder to the repository root.
4. Open repository Settings > Pages.
5. Select deployment from the main branch and root folder, then save.
6. Wait for the Pages URL to appear in Settings > Pages.

GitHub Pages hosts the static website, not a complete streaming backend. For dependable public streaming, plan audio hosting separately. Do not upload private artist demos or confidential files to a public repository.

BEFORE LAUNCH
- Replace all sample artist names and track titles.
- Add your official email and social links.
- Add your improved logo and approved artist images.
- Confirm music ownership/permissions and artist agreements.
- Test on Android and desktop.
- Add a privacy notice if you collect personal information.
